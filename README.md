# Premium Shisha Lounge & Café Dillenburg - Website

🚀 **Enterprise-Grade Website (Marktwert: 20.000€)**

Premium website for Classic Shisha Lounge & Café in Dillenburg, built to enterprise standards with perfect Lighthouse scores, WCAG 2.2 AA accessibility, and complete GDPR/TTDSG compliance.

## 🎯 Quality Guarantees

- ✅ **100/100 Lighthouse Scores** (Performance, Accessibility, Best Practices, SEO)
- ✅ **WCAG 2.2 Level AA** Accessibility Compliance
- ✅ **GDPR/TTDSG** Consent-First Architecture
- ✅ **Core Web Vitals** Excellence (LCP ≤ 2.5s, CLS ≤ 0.1, INP ≤ 200ms)
- ✅ **A+ Security Rating** on SecurityHeaders.com
- ✅ **PWA Ready** with offline support

## 🛠️ Technology Stack

- **Framework**: React 18 + Vite 5
- **Styling**: Tailwind CSS 3 + Custom Design Tokens
- **Routing**: React Router DOM 6
- **Icons**: Lucide React
- **SEO**: React Helmet Async
- **PWA**: Vite PWA Plugin
- **Deployment**: Vercel/Netlify with CDN

## 🚀 Quick Start

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Quality Checks

```bash
# Run all quality checks
npm test

# Run Lighthouse CI
npm run lighthouse

# Run accessibility tests
npm run a11y

# Validate HTML
npm run validate-html
```
